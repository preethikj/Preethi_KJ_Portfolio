# Preethi KJ Portfolio

Static portfolio website with a clean, interview-friendly asset structure.

## Structure

```text
Preethi_KJ_Portfolio/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    ├── documents/
    │   └── Preethi_Kiri_Jeyaprakash_Resume.pdf
    └── images/
        ├── cinebook/
        ├── realnest/
        └── online-quiz/
```

- `index.html` contains the page structure/content.
- `assets/css/style.css` contains all portfolio styling.
- `assets/js/script.js` contains the project screenshot lightbox/gallery behaviour.
- `assets/documents/` stores the resume as a normal PDF asset.
- `assets/images/` groups screenshots by project.

Extract the ZIP before opening `index.html` so all relative asset paths resolve correctly.
